# RSA2015: Provide `<inheritdoc/>` on members that implement or override an abstraction

| Property | Value |
|-|-|
| **Rule ID** | RSA2015 |
| **Category** | Design |
| **Default severity** | Warning |
| **Enabled by default** | Yes |
| **Code fix** | No |
| **StyleCop equivalent** | None |

## Cause

A member implements an interface member, or overrides an abstract member, and has no
`<inheritdoc/>` in its documentation comment.

## Rule description

A member that implements an interface member or overrides an abstract member restates a contract
documented once at its source, so it points back there with `<inheritdoc/>` instead of duplicating
or omitting the documentation. RSA2015 reports on whichever type directly declares the member:

```csharp
public interface IReader
{
    string Read(string key);
}

public class Reader : IReader
{
    /// <inheritdoc/>
    public string Read(string key) => key;
}
```

**Inheriting an implementation from a base class does not itself require `<inheritdoc/>` at the
derived class** — only the type that actually writes the member out needs the tag. A member that is
itself `abstract`, re-declaring the contract rather than fulfilling it, is excluded; [RSA2014](RSA2014.md)
owns documenting that one instead.

**RSA2015 does not currently check an event declared with the field-like `event Handler Changed;`
shorthand.** Declare it with `event Handler Changed { add; remove; }` instead if it implements an
interface event and needs the check.

## How to fix violations

Add `/// <inheritdoc/>` to the member. There is no code fix — the choice of whether to also add
`<inheritdoc/>` parameters like `cref` is an authoring decision.

## When to suppress warnings

Suppress on a member whose implementation deliberately diverges from its contract enough that
restating the base documentation instead of the standard `<inheritdoc/>` reference is clearer.

## Suppress a warning

```csharp
[System.Diagnostics.CodeAnalysis.SuppressMessage("Design", "RSA2015:Provide <inheritdoc/> on members that implement or override an abstraction", Justification = "<explain why>")]
```

```csharp
#pragma warning disable RSA2015 // '{0}' implements or overrides a documented member; add <inheritdoc/>
#pragma warning restore RSA2015
```

```ini
[*.cs]
dotnet_diagnostic.RSA2015.severity = none
```

See [Suppress a warning](../README.md#suppress-a-warning) in the package README.
