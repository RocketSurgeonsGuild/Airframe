# RSA2016: Remove redundant type alias

| Property | Value |
|-|-|
| **Rule ID** | RSA2016 |
| **Category** | Design |
| **Default severity** | Warning |
| **Enabled by default** | Yes |
| **Code fix** | Yes ("Remove redundant type alias") |

## Cause

A local type alias uses the type's own name, and every reference to that alias still resolves to
the same type after the directive is removed.

## Rule description

A namespace import or the enclosing namespace can already make a type available by its simple
name. An additional same-name alias adds no information unless it resolves ambiguity or preserves
a different binding. The rule removes the directive in a temporary compilation and checks each
alias reference, including attribute names and XML documentation references, against the original
target type before reporting it. Source types are resolved in the temporary compilation as well.

Aliases that give a type a different name, resolve ambiguity, or would bind to a different type
are retained. Global aliases and namespace aliases are outside this file-local rule's scope.
Nullable reference type aliases are retained to preserve their annotations. Unused aliases are
left to IDE0005.

## How to fix violations

Remove the redundant using directive:

```csharp
using Example.Model;
using Item = Example.Model.Item; // RSA2016

class Consumer
{
    public Item Create() => new Item();
}
```

becomes:

```csharp
using Example.Model;

class Consumer
{
    public Item Create() => new Item();
}
```

The fix retains comments and surrounding trivia, rechecks that removal is safe, and supports
Fix All in a document, project or solution. Generated code is excluded.

```bash
dotnet format analyzers --diagnostics RSA2016
```

## When to suppress warnings

Suppress when an otherwise redundant alias deliberately documents a chosen type at a boundary.

```ini
[*.cs]
dotnet_diagnostic.RSA2016.severity = none
```

See [Suppress a warning](../README.md#suppress-a-warning) in the package README.
