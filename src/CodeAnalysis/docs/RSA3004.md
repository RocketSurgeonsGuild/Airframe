# RSA3004: Provide an explicit scheduler for AutoRefresh

| Property | Value |
|-|-|
| **Rule ID** | RSA3004 |
| **Category** | Performance |
| **Default severity** | Warning |
| **Enabled by default** | Yes |
| **Code fix** | No |

## Cause

A call to DynamicData's `AutoRefresh(...)` extension method did not supply its optional trailing
`IScheduler` argument.

## Rule description

`AutoRefresh` re-evaluates its selector (or, on the no-selector overload, `WhenAnyPropertyChanged`)
every time a tracked property changes, for every item in the source. Without an explicit scheduler,
that re-evaluation work runs on whatever scheduler the underlying property-change notifications
originate from — for a UI-bound `INotifyPropertyChanged` implementation that is very often the UI
thread, turning frequent property churn into UI-thread work with no way to move it later without
touching every call site again. Supplying a deliberately chosen scheduler up front — for example
`TaskPoolScheduler.Default` to push the work off the UI thread — makes that choice explicit and
reviewable at the call site, rather than inherited implicitly.

RSA3004 applies to every `AutoRefresh` overload that carries a trailing `IScheduler` parameter,
whether or not the overload also takes a property-accessor selector.

## How to fix violations

Pass an explicit `IScheduler` argument.

```csharp
// Violates RSA3004
cache
   .Connect()
   .AutoRefresh(x => x.Thing)
   .Subscribe();
```

```csharp
// Satisfies RSA3004
cache
   .Connect()
   .AutoRefresh(x => x.Thing, scheduler: TaskPoolScheduler.Default)
   .Subscribe();
```

## When to suppress warnings

Suppress where the default scheduler behavior is already the intended behavior for that call site
(for example, a non-UI-bound source where the notification origin is already known and acceptable)
and adding a scheduler argument would just restate the default.

## Suppress a warning

```csharp
[System.Diagnostics.CodeAnalysis.SuppressMessage("Performance", "RSA3004:Provide an explicit scheduler for AutoRefresh", Justification = "<explain why>")]
```

```csharp
#pragma warning disable RSA3004 // Provide an explicit scheduler for AutoRefresh
#pragma warning restore RSA3004
```

```ini
[*.cs]
dotnet_diagnostic.RSA3004.severity = none
```
