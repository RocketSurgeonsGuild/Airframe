# RSA2007: Readonly fields should appear before mutable fields

| Property | Value |
|-|-|
| **Rule ID** | RSA2007 |
| **Category** | Design |
| **Default severity** | Warning |
| **Enabled by default** | Yes |
| **Code fix** | Yes (shared ordering fix) |
| **StyleCop equivalent** | SA1214 |

## Cause

A `readonly` field was declared after a mutable field of the same accessibility.

## Rule description

Readonly fields are declared before mutable fields of the same accessibility, so a reader sees what
cannot change first. This is one of the seven RSA2XXX
[member-ordering rules](../README.md#member-ordering). RSA2007 never applies to interfaces or
enumerations.

## How to fix violations

Move `readonly` fields above mutable fields of the same accessibility, or run the shared ordering
fix (supports Fix All):

```bash
dotnet format analyzers --diagnostics RSA2001,RSA2002,RSA2003,RSA2004,RSA2005,RSA2006,RSA2007
```

## When to suppress warnings

If you already use StyleCop's SA1214 and are not ready to retire it in favor of RSA2007, suppress
one or the other, not both — see [Running alongside StyleCop](../README.md#running-alongside-stylecop).

## Suppress a warning

```csharp
[System.Diagnostics.CodeAnalysis.SuppressMessage("Design", "RSA2007:Readonly fields should appear before mutable fields", Justification = "<explain why>")]
```

```csharp
#pragma warning disable RSA2007 // Readonly fields should appear before mutable fields
#pragma warning restore RSA2007
```

```ini
[*.cs]
dotnet_diagnostic.RSA2007.severity = none
```

See [Suppress a warning](../README.md#suppress-a-warning) in the package README.
