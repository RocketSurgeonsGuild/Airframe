# RSA0003: Do not return a nullable task

| Property | Value |
|-|-|
| **Rule ID** | RSA0003 |
| **Category** | Nullability |
| **Default severity** | Warning |
| **Enabled by default** | Yes |
| **Code fix** | No |

## Cause

A public or protected method, property, or indexer declares a nullable `Task`, `Task<T>`, `ValueTask`, or
`ValueTask<T>` return type.

## Rule description

A task represents a completion, and a completion either exists or the member has not returned yet
- it should never itself be `null`. The compiler's nullable reference type analysis does not flag
`Task<T>?`: it is a legal, well-formed annotation, and flagging it would require judging the
annotation itself rather than the flow that reaches it.

```csharp
// Violates RSA0003
public Task<Item>? FindAsync(string key) => _cache.ContainsKey(key) ? LoadAsync(key) : null;
```

```csharp
// Satisfies RSA0003
public Task<Item?> FindAsync(string key) => _cache.ContainsKey(key) ? LoadAsync(key) : Task.FromResult<Item?>(null);
```

**A nullable type argument does not match.** `Task<Item?>` is a nullable *result*, not a nullable
task - the task itself always completes, it just may complete with `null`. Only the outer task type
being nullable is the violation.

**An override and an explicit interface implementation are excluded.** Neither author chose the
nullability of the contract they are fulfilling - the abstract or interface member that originates
it is where RSA0003 reports instead.

## How to fix violations

Return `Task.CompletedTask`, `Task.FromResult(...)`, or a default `ValueTask`/`ValueTask<T>`
instead of `null`, and drop the `?` from the declared task type. If the caller genuinely needs to
distinguish "no result" from "a result," make that nullability part of the task's result type
instead of the task itself.

## When to suppress warnings

Suppress in generated or interop code where a nullable task type is dictated by an external API
this rule cannot see through.

## Suppress a warning

```csharp
[System.Diagnostics.CodeAnalysis.SuppressMessage("Nullability", "RSA0003:Do not return a nullable task", Justification = "<explain why>")]
```

```csharp
#pragma warning disable RSA0003 // '{0}' returns a nullable {1}; a task represents a completion and should never itself be null
#pragma warning restore RSA0003
```

```ini
[*.cs]
dotnet_diagnostic.RSA0003.severity = none
```

See [Suppress a warning](../README.md#suppress-a-warning) in the package README for the
`SuppressMessageAttribute` form and when to prefer it over `.editorconfig`.
