# RSA1003: Use the `out` parameter overload of `ToProperty`

| Property | Value |
|-|-|
| **Rule ID** | RSA1003 |
| **Category** | Usage |
| **Default severity** | Error |
| **Enabled by default** | Yes |
| **Code fix** | Yes |

## Cause

`ToProperty` was called with a property-selecting lambda (`x => x.Value`) instead of the
`out ObservableAsPropertyHelper<T>` overload.

## Rule description

`ToProperty` has an overload that takes an expression selecting the backing property and one that
takes an explicit `out` parameter. The expression overload resolves the property by name at
runtime via reflection; the `out` overload binds the backing field directly at the call site and is
both faster and safer under renames. RSA1003 flags the expression-selector overload wherever the
`out` overload is available.

## How to fix violations

Switch to the `out` overload, assigning the backing field directly.

```csharp
// Violates RSA1003
var _ =
    Observable
       .Return(Unit.Default)
       .ToProperty(this, x => x.Value);
```

```csharp
// Satisfies RSA1003
Observable
   .Return(Unit.Default)
   .ToProperty(this, nameof(Value), out _value);
```

## When to suppress warnings

Suppress only when the `out` overload is unavailable for the target type (for example, an older
ReactiveUI version pinned by the project). Otherwise prefer the fix.

## Suppress a warning

```csharp
#pragma warning disable RSA1003 // Out parameter assignment
#pragma warning restore RSA1003
```

```ini
[*.cs]
dotnet_diagnostic.RSA1003.severity = none
```

See [Suppress a warning](../README.md#suppress-a-warning) in the package README for the
`SuppressMessageAttribute` form and when to prefer it over `.editorconfig`.
