# RSA0002: Do not return a nullable collection

| Property | Value |
|-|-|
| **Rule ID** | RSA0002 |
| **Category** | Nullability |
| **Default severity** | Warning |
| **Enabled by default** | Yes |
| **Code fix** | No |

## Cause

A public or protected method or property declares a nullable collection return type - an array, or
a type assignable to the non-generic `IEnumerable`, excluding `string`.

## Rule description

The compiler's nullable reference type analysis verifies that flow matches a declared annotation;
it has no opinion on whether the annotation itself is a good contract. `IEnumerable<T>?`,
`List<T>?`, and `T[]?` are all legal, compiler-satisfied return types, and all force every caller
across that boundary to null-check before it can enumerate - work an empty collection makes
unnecessary:

```csharp
// Violates RSA0002
public IEnumerable<Item> Find(string key) => _cache.TryGetValue(key, out var items) ? items : null;
```

```csharp
// Satisfies RSA0002
public IEnumerable<Item> Find(string key) => _cache.TryGetValue(key, out var items) ? items : [];
```

**An override and an explicit interface implementation are excluded.** Neither author chose the
nullability of the contract they are fulfilling - the abstract or interface member that originates
it is where RSA0002 reports instead.

## How to fix violations

Return `[]`, `Array.Empty<T>()`, or `Enumerable.Empty<T>()` instead of `null`, and drop the `?` from
the declared return type.

## When to suppress warnings

Suppress where the distinction between "no items" and "no answer" is itself the contract - for
example, a lookup that must be able to report "the key does not exist" separately from "the key
exists and has no items," and models that with a null collection rather than a `bool`
`TryFind`-style overload or an `Optional<T>`.

## Suppress a warning

```csharp
[System.Diagnostics.CodeAnalysis.SuppressMessage("Nullability", "RSA0002:Do not return a nullable collection", Justification = "<explain why>")]
```

```csharp
#pragma warning disable RSA0002 // '{0}' returns a nullable collection; return an empty collection instead of null
#pragma warning restore RSA0002
```

```ini
[*.cs]
dotnet_diagnostic.RSA0002.severity = none
```

See [Suppress a warning](../README.md#suppress-a-warning) in the package README for the
`SuppressMessageAttribute` form and when to prefer it over `.editorconfig`.
