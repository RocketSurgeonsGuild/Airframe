# RSA1004: Provide a well-formed lambda expression for `WhenAnyValue`

| Property | Value |
|-|-|
| **Rule ID** | RSA1004 |
| **Category** | Usage |
| **Default severity** | Error |
| **Enabled by default** | Yes |
| **Code fix** | Yes |

## Cause

A `this.WhenAnyValue(...)` selector's body was not a simple member access rooted at the lambda
parameter.

## Rule description

Like RSA1002 for `BindTo`, `WhenAnyValue` resolves the observed property from the selector
expression tree at compile time. A selector that closes over `this` instead of using the lambda
parameter (`x => Value` instead of `x => x.Value`) compiles, but `WhenAnyValue` observes the wrong
member or none at all.

## How to fix violations

Root the selector at the lambda parameter.

```csharp
// Violates RSA1004
this.WhenAnyValue(x => Value).Subscribe();
```

```csharp
// Satisfies RSA1004
this.WhenAnyValue(x => x.Value).Subscribe();
```

## When to suppress warnings

Don't. RSA1004 reports a default severity of `Error` for the same reason RSA1002 does: the flagged
shape silently observes the wrong property.

## Suppress a warning

```csharp
#pragma warning disable RSA1004 // Unsupported expression missing member access prefix.
#pragma warning restore RSA1004
```

```ini
[*.cs]
dotnet_diagnostic.RSA1004.severity = none
```

See [Suppress a warning](../README.md#suppress-a-warning) in the package README for the
`SuppressMessageAttribute` form and when to prefer it over `.editorconfig`.
