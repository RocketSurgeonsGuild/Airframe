# RSA0006: Do not use a nullable boolean to model three states

| Property | Value |
|-|-|
| **Rule ID** | RSA0006 |
| **Category** | Nullability |
| **Default severity** | Info |
| **Enabled by default** | Yes |
| **Code fix** | No |

## Cause

A public or protected property is declared `bool?`.

## Rule description

A `bool?` property is very often not modeling "true or false, with the occasional unknown" - it is
modeling three distinct, meaningful states, with `null` standing in for a third value the type
never names. A named enum says what that third state actually means:

```csharp
// Violates RSA0006
public bool? IsApproved { get; set; }
```

```csharp
// Satisfies RSA0006
public ApprovalState Approval { get; set; }

public enum ApprovalState
{
    Pending,
    Approved,
    Rejected
}
```

**An override and an explicit interface implementation are excluded.** Neither author chose that
member's type - the abstract or interface declaration that originated it is where RSA0006 reports
instead.

## How to fix violations

Replace the property's type with a named `enum` whose members say what each state means, and update
its consumers to match against the enum instead of checking for `null`.

## When to suppress warnings

Suppress on a genuine three-state UI binding contract, such as a tri-state checkbox's `IsChecked`,
where the binding infrastructure itself expects `bool?` and a project-specific enum would just be
translated back into one at the binding boundary. Suppress as well on a wire-format DTO where
"absent" and "false" are two different things the API contract needs to distinguish, and the enum
would only relocate that meaning rather than clarify it. This analyzer cannot tell either case apart
from a genuine three-state smell on its own, so both are left to `[SuppressMessage]` at the
declaration rather than an exclusion this analyzer would have to guess at.

## Suppress a warning

```csharp
[System.Diagnostics.CodeAnalysis.SuppressMessage("Nullability", "RSA0006:Do not use a nullable boolean to model three states", Justification = "<explain why>")]
```

```csharp
#pragma warning disable RSA0006 // '{0}' is a nullable bool; a named enum expresses the three states more clearly than true, false, and null
#pragma warning restore RSA0006
```

```ini
[*.cs]
dotnet_diagnostic.RSA0006.severity = none
```

See [Suppress a warning](../README.md#suppress-a-warning) in the package README for the
`SuppressMessageAttribute` form and when to prefer it over `.editorconfig`.
