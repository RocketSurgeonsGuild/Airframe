# RSA2009: File name should match the first type name

| Property | Value |
|-|-|
| **Rule ID** | RSA2009 |
| **Category** | Design |
| **Default severity** | Warning |
| **Enabled by default** | Yes |
| **Code fix** | No |
| **StyleCop equivalent** | SA1649 |

## Cause

A file's name did not match the first type declared in it.

## Rule description

A file is named for the type it declares, so a type can be found from its file name alone. RSA2009
accepts a generic arity or a partial suffix, so `Thing{T}.cs`, ``Thing`1.cs`` and
`Thing+Statics.cs` all name `Thing`.

## How to fix violations

Rename the file to match the first type it declares. There is no code fix — renaming a file is left
to your IDE's rename-file action so references and any file-scoped tooling stay in sync.

## When to suppress warnings

Suppress on a file whose name follows a project-specific convention that intentionally diverges
from its type name (a generated file with a fixed name, for example).

## Suppress a warning

```csharp
[System.Diagnostics.CodeAnalysis.SuppressMessage("Design", "RSA2009:File name should match the first type name", Justification = "<explain why>")]
```

```csharp
#pragma warning disable RSA2009 // File name '{0}' does not match the first type declared in it, '{1}'
#pragma warning restore RSA2009
```

```ini
[*.cs]
dotnet_diagnostic.RSA2009.severity = none
```

See [Suppress a warning](../README.md#suppress-a-warning) in the package README.
