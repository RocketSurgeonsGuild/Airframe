# RSA2012: Conditional compilation should not span member declarations

| Property | Value |
|-|-|
| **Rule ID** | RSA2012 |
| **Category** | Design |
| **Default severity** | Warning |
| **Enabled by default** | Yes |
| **Code fix** | No |
| **StyleCop equivalent** | None |

## Cause

A `#if`/`#else`/`#endif` block wrapped one or more whole member declarations.

```csharp
#if XAMARIN_IOS
    public void StartRangingBeacons(CLBeaconRegion region) => ...
#else
    public void StartRangingBeacons(CLBeaconIdentityConstraint constraint) => ...
#endif
```

## Rule description

A block like this hides half a type's surface from anyone reading one configuration, leaves the
layout rules unable to see the members it excludes, and stops the reorder, which cannot move a
member past it without changing which symbols compile it. **Conditional compilation inside a
member body is not reported**, because that is how multi-targeting is normally written:

```csharp
public int Start() =>
#if XAMARIN_IOS
    _manager.Value.StartMonitoring(region, accuracy);
#else
    _manager.Value.StartMonitoring(region);
#endif
```

## How to fix violations

Move the directive inside the members it guards, or split the type across per-target files. There
is no code fix — see [File structure](../README.md#file-structure) for why: a directive pair whose
meaning depends on where it sits among the members is exactly the case the shared ordering fix
declines to touch, so the edit is intentionally left to you.

## When to suppress warnings

Suppress where the multi-targeted member set is large enough that splitting into per-target partial
files would be a bigger structural change than the project is ready to make yet.

## Suppress a warning

```csharp
[System.Diagnostics.CodeAnalysis.SuppressMessage("Design", "RSA2012:Conditional compilation should not span member declarations", Justification = "<explain why>")]
```

```csharp
#pragma warning disable RSA2012 // Move the conditional compilation inside the members it guards, or split '{0}' across per-target files
#pragma warning restore RSA2012
```

```ini
[*.cs]
dotnet_diagnostic.RSA2012.severity = none
```

See [Suppress a warning](../README.md#suppress-a-warning) in the package README.
